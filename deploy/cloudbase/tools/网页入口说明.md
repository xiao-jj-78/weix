# 腾讯云网页入口

`../public/` 是独立的静态网站目录，复用电脑版已有任务、SDK、朋友圈用户名单和 AI 服务商界面。云端只负责访问控制与转发；微信、C# SDK 和实际自动化仍在 Windows 微信节点运行。需要在 Windows 的官方微信窗口由用户扫码。

生成网页：

```powershell
python -X utf8 deploy/cloudbase/tools/export_dashboard.py
```

只导入 HTML 模块，不会启动服务、读取本机 AI 配置或密钥、访问微信或发布云资源。`--output` 可指定另一输出目录，并复制页面使用的三个静态资源。

当前 `public/cloud-config.js` 已配置本项目实际 HTTPS 后端：`https://jou-d4gq7a3cqf51e6caa.service.tcloudbase.com/wechat-workspace-api`。重新导出会保留该地址。后续更换环境时将 `API_BASE` 改为实际后端入口，末尾不要再加 `/api`；设为空字符串则同源访问 `/api/`。此文件公开，不能写访问码或 AI 密钥。后端需要精确允许静态网站的来源；不要改成允许任意网站携带访问码访问。

资源使用 `./` 路径，可放在静态托管的子目录。后端地址默认是当前网站来源，不会从网址查询参数读取访问码或后端地址。

打开网页后输入部署时设置的**浏览器访问码**。它与腾讯云登录、Windows 节点连接码、微信登录及 AI 密钥相互独立。浏览器通过带访问码的 `GET /api/cloud/status` 校验，成功后仅保存在本次 `sessionStorage` 会话；退出云端或收到 401/403 时清除。未登录时停止 API 轮询，并禁用工作区交互。

每次写操作生成独立的 `X-Idempotency-Key`。网页不会自动重试操作；超时或响应无法读取时提示先查任务、日志或智能回复状态，以免重复执行。状态读取可以自动恢复。普通请求等待 38 秒，联系人、插件执行与 AI 预览等待 115 秒。

界面明确区分“访问码已验证”和“Windows 节点在线”。节点离线时，云端访问成功不代表能登录微信或执行任务。锁屏及远程桌面断开可能影响 Windows 自动化。

本地验证：

```powershell
python -X utf8 deploy/cloudbase/tools/test_cloud_dashboard.py
```
