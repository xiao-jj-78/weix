# 微信工作台 1.1 · Visual Studio 与多端互通

升级交付保存在 `deliverables/升级版-微信工作台/`，原有交付物保留。先打开其中的 `00-开始使用.html`，查看三种启动方式、截图和验证范围。

## 三种运行方式

| 入口 | 用途 |
|---|---|
| `01-可视化版.cmd` | 启动本机服务并打开 Windows 原生 MAUI 工作台 |
| `02-后台托管版.cmd` | 隐藏运行电脑服务与 C# SDK 宿主，打开网页工作台 |
| `03-独立插件版.cmd` | 启动同一后台服务，直接打开插件与微信会话面板 |
| `04-停止后台服务.cmd` | 安全停止启动器自己创建的服务和 SDK；不退出官方微信 |

这三种方式共享任务、配置与日志，不是相互隔离的微信账号或不同协议客户端。MAUI 的“启动本机服务”自己创建的后台服务随应用退出而清理；启动器创建的后台服务持续运行，使用“停止后台服务”退出。

## 连接与登录

电脑日常使用请双击 `08-直接打开微信.cmd`，或在原生工作台点击“打开 / 继续使用微信”。程序自动连接本机服务并准备 SDK；已有一个窗口就显示它，多个窗口由本人选择，没有窗口才启动官方客户端。高级 IP / 端口设置默认收起。本机使用无需腾讯云登录或云访问码；云访问码仅用于远程管理网页。

这一步不会读取账号来猜测登录状态，也不主动退出微信或清理官方保存的状态。是否需要扫码或手机确认由官方客户端决定；程序不能代替本人完成确认。

1. Windows 使用 `127.0.0.1`，服务端口 `8765`。启动 MAUI 后点“连接电脑”；源工程调试时也可以点“启动本机服务”。
2. 新版 `微信工作台-MAUI-Android.apk` 已改为手机独立首页，不需要电脑；可直接配置 AI、授权微信通知和按作者辅助朋友圈操作。详见 `手机独立版使用说明.md`。旧 Kotlin 遥控版及网页仍可通过局域网连接电脑。
3. 在官方微信完成登录；优先使用它已保留的登录状态。如官方要求扫码或手机确认，由本人完成。程序不接收微信密码或验证码。
4. 先运行“SDK 兼容性检查”和“桌面会话快照”。这两项不操作微信窗口。
5. 微信登录且暴露兼容 UI Tree 后，可按需运行“读取 SDK 会话”和“读取通讯录姓名”。实际使用上游 SDK 公开接口；未登录或不兼容时显示失败。

后台托管指本机服务持续运行，不代表个人微信能在锁屏、注销、无交互桌面的服务器上自动操作。独立插件由本项目宿主加载，**没有向微信进程注入 DLL，也没有交付微信内部嵌入式插件**。微信 4.x 未开放辅助功能树时，本版会给出错误，不自动修改进程内存或系统设置。

## 内置云端浏览器与多微信管理

双击 `05-连接腾讯云.cmd`，会启动本机服务、SDK 和云连接器，并打开原生工作台的“云端与多微信”。内置浏览器使用独立、持久的本机浏览器配置；点击“复制云访问码”后在网页中粘贴，访问码只留在当前 Windows 用户的加密配置中，剪贴板副本会在 60 秒后或应用退出时清除（如果剪贴板内容未被替换）。

左侧显示同一 Windows 桌面的官方微信窗口，可备注、显示指定窗口和“伴随排列”；点击“恢复伴随”或关闭原生工作台会恢复原来的窗口位置。伴随窗口仍是官方微信自己的窗口。Windows 负责本机窗口管理，安卓与网页负责远程列表和控制。

窗口列表不读取登录数据，也不把窗口数量当成账号数量。需要识别账号时手动点击“读取已登录账号”，结果标记为上次读取状态；此操作通过现有 C# SDK，可能切换官方窗口。窗口备注随当前进程有效，重启客户端后需核对。能否打开多个账号、复用登录状态，由官方客户端和当前账号决定；本程序不强制多开或绕过登录。

微信仍运行在 Windows 节点；腾讯云托管网页和指令桥接，电脑需保持开机及可交互桌面。内置云网页的授权和官方微信的登录是各自独立的。

## 在 Visual Studio 继续

优先打开项目根目录 `WeChatWorkspace.Windows.slnx`，可直接在 Windows 调试同一套 MAUI 源码。本轮已在 Visual Studio 中实际启动该工程并进入调试运行状态。需要同时查看 Android 与 C# SDK 时，打开完整的 `WeChatWorkspace.slnx`。本机已核验安装 Visual Studio Community 2026（`D:/net`）、.NET SDK `10.0.402` 和 MAUI Windows / Android 工作负载。

- 将 `WeChatLikeMaui` 设置为启动项目，选择 Windows 本地计算机运行；界面位于 `build/maui/WeChatLikeMaui/MainPage.xaml`。
- 安卓目标使用已安装的 Android SDK 与 JDK；不要为了本项目重复安装工作负载。
- C# SDK 宿主与插件在解决方案的 `sdk` 项目中。上游原始 `analysis` 保持不变，编译引用在 `build/sdk/vendor`，并保留许可证和源码校验清单。
- 当前 Windows 与 SDK 包依赖 .NET 10 运行时；SDK 宿主还需要 ASP.NET Core Runtime 10.x，MAUI 需要 Windows App Runtime。本机已可运行；复制到其他电脑时按运行时提示安装。

Windows 专用工程使用独立的中间目录，可避免 Visual Studio 默认切到 Android 模拟器而要求重复安装组件；它引用的页面与服务代码和跨平台工程一致。

## 升级内容

- 原生 MAUI 与网页共享深青、绿与浅色界面；展示真实连接状态、运行任务、退出码、设备、可选日志、参数保存和 SDK 结果。
- Windows 本机启动按钮真正开启 `--serve` 遥控服务；源代码与打包版都通过同一任务调度链。
- API 客户端同时检查 HTTP 状态及 JSON `ok`，避免把业务失败显示为成功。
- 任务启动互斥、参数校验、配置原子保存和退出清理；遥控任务同样应用定点引擎的已保存参数。
- C# 宿主实际集成 `WeChatAuto4x.SDK 2.1.4`，支持官方微信打开、后台探测、按需账号与会话读取、通讯录姓名读取及独立 DLL 插件。
- AI 面板参考 [CC Switch](https://github.com/farion1231/cc-switch) 的服务商方案管理：新增、切换、导入 JSON、脱敏导出、提示词与样例预览。支持 OpenAI 兼容接口和 Ollama；不会自动读取 CC Switch 的私有配置。
- 朋友圈支持搜索、手动添加、读取联系人及多选名单。名单保存在 `replica_authors`；执行器在点赞前再次核对完整作者名及关键词，不接受上游的昵称子串兜底。名单只应用于“定点点赞”，同名用户仍需用唯一显示名人工核对。

## AI 与朋友圈用户选择

进入 AI 面板，保存接口地址、模型和密钥。密钥经当前 Windows 用户 DPAPI 加密，只保存在本机，读取配置和导出 JSON 均不会返回密钥。使用“生成预览”检查样例答复，此操作不会向微信发送消息。

需要自动答复时，选择 1–10 位私聊联系人，保存规则，再明确点击启用。启用后会把所选私聊的新消息发送到配置的 AI 服务，并将生成文本回复到该微信会话；首次会建立历史基线，忽略历史消息、自己发送的消息和群聊。支持回复间隔、每小时上限及本次托管时长，重启不会自动启用。附件 SDK 的消息监听实现为空，本版使用公开 SDK 轮询；真实稳定性仍需登录后的客户端联调。

在“朋友圈用户”或原生端参数设置中勾选用户，或逐行输入与朋友圈显示一致的名字，保存后再启动“定点点赞”。每轮每位所选用户最多定位一条符合条件的动态；找不到、名字不一致或关键词不匹配就跳过，不扩大到其他用户。适配器使用 UI 定位，不初始化微信数据库读密钥的模块。原有手机/电脑通用点赞任务仍按原脚本规则执行。

Agnes AI 的兼容地址为 `https://apihub.agnes-ai.com/v1`。本机已按用户指定保存 Agnes 方案并查询可用模型；具体实测结果见交付验证记录。复制到其他 Windows 用户或电脑时需重新填入密钥。请在应用密码框填写替换后的密钥，不要把密钥写入源码、文档或截图。
