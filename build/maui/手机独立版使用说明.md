# 微信工作台 · 小米手机独立版 1.4

安装 `微信工作台-手机独立版.apk` 后直接打开即可，不需要连接电脑、不填写电脑 IP，也不需要启动腾讯云 Windows 节点。AI 需要手机能联网及你自己的有效接口额度。

## 安装与配置

1. 将 APK 发送到你的小米手机，在手机中打开安装。它与旧 MAUI 遥控版使用同一应用标识和开发签名，可覆盖升级；原有 Kotlin 遥控 APK 是另一个应用。
2. 在首页点“首次设置 / 权限”，进入 AI 设置填写基础地址、模型和 API 密钥，再保存。Agnes 可用基础地址 `https://apihub.agnes-ai.com/v1`，默认模型名 `agnes-3.0-flash`；模型可用性由你的服务账号决定。安装包不含你的密钥，需在手机填写。
3. 在回复预览输入一段文字，点“生成回复”。生成结果可编辑和复制，不会据此自动发送微信。
4. 在首次设置中开启悬浮窗权限，返回首页点“启动微信助手”。打开官方微信后使用旁边的悬浮工具球进入 AI、朋友圈辅助、暂停和设置。需要登录或切换账号时按官方提示完成。

## 微信消息与智能回复

- 点“开启通知使用权”，阅读说明后在安卓系统中授权本应用。仅处理官方包 `com.tencent.mm` 的新通知；不读取聊天数据库，不补发历史通知。通知正文只保留在进程内存中，最多 30 条。
- 进入“微信消息”，选择通知生成回复，核对内容后点“确认并回复所选通知”。仅在这条通知暴露安卓快捷回复入口、仍未过期且内容未变化时提交；返回“已提交”不代表微信已送达。
- 微信版本或通知类型没有快捷回复入口时，使用“复制回复”并到微信粘贴。没有通知权限或微信隐藏通知正文时，仍可手动粘贴内容使用 AI。
- 如需自动回复，先按完整通知会话标题填写名单、保存，验证预览后再显式启用。只对名单内且有快捷回复入口的新通知尝试回复；忙碌期间不积压自动任务。发送前再次核对通知，防止回复到已变化的会话。
- 发送记录只保存有限数量的通知指纹，用于避免重发；调用结果不确定时不自动重试。服务重新接入、配置或名单改变、处理异常后自动关闭。可随时点“立即关闭自动回复”。
- 通知标题不是唯一联系人 ID，同名会话和群聊应人工核对，不宜仅按昵称启用无人回复。自动回复会把匹配的新通知正文发送到你配置的 AI 服务。

## 按作者辅助朋友圈点赞

1. 不再输入作者名。启动助手后在官方微信打开“通讯录”或“朋友圈”，点悬浮球 → “识别 / 选择好友” → “识别微信当前页”，勾选后点“保存所选好友”，最多 20 位。收起工具球、手动翻页后可继续识别；本次候选只在内存中，所选名单保存在手机。

同名候选会标出并禁止保存；显示名不是微信唯一 ID，跨页同名仍需本人核对，请先给同名好友设置不同备注。切换微信账号后清空并重新选择。没有读取整个聊天数据库或自动获得完整通讯录。
2. 阅读权限说明并在系统中启用“微信工作台 · 朋友圈辅助”。该服务仅限官方微信可见窗口，不截屏上传，不操作其他应用。
3. 点“准备本轮辅助点赞”，选择一位作者，回到官方微信并手动打开朋友圈，使一条目标动态完整显示。
4. 本轮 60 秒内，只在能匹配唯一完整作者名、对应评论菜单及明确“赞”按钮时尝试一次。遇到多个同名候选、页面位置变化、已点赞或无法识别控件时停止；不盲点、不自动滚动。可随时取消本轮。

这一功能已经实现本地执行层，但尚未在你的小米手机和微信版本上验证。作者同名、界面控件变化或微信未开放可访问节点时，不能保证可执行；请在微信核对最终点赞结果。

## 悬浮工具球与自动巡检

日常操作：打开本应用 → 启动微信助手 → 使用官方微信旁的悬浮工具球。首次授权由本人在安卓设置中完成；首次设置只授权，首页启动后才显示工具球。工具球可以拖动，展开后可生成和编辑回复、核对所选通知后发送、管理朋友圈辅助或暂停。停止助手会关闭悬浮窗。

在朋友圈辅助中识别并勾选好友，按提示启用辅助服务，再明确开启自动巡检。设置会被记住，下次本人启动助手时尝试恢复；不会开机静默启动微信。关闭自动巡检会清除该设置。

约每 15 秒检查一次，仅在手机解锁、官方微信朋友圈前台且能确认列表顶部时尝试刷新。第一次将已有内容作为基线，随后只尝试名单中可唯一识别、带近期标记的新文字动态。纯图片、未知界面、同名歧义或无法确认按钮时跳过；离开页面、锁屏或暂停时停止动作，恢复后重新建立基线。不能保证别人发出后立刻发现、发现所有动态或成功点赞。

这一版本的悬浮窗、输入法、系统权限、后台存活及自动朋友圈操作尚未通过安卓真机测试。首次手机测试请先保持关闭自动回复和自动巡检，确认普通悬浮窗和手动预览正常后再按需开启。

## 小米后台运行

确认系统允许微信显示通知正文，且本应用有通知使用权。若 MIUI / HyperOS 清理后台导致服务断开，在应用信息中检查自启动、省电限制与相关授权；具体菜单随系统版本变化，请由本人在手机设置。

手机锁屏、微信不产生通知、系统清理进程或隐藏正文时，无法保证持续回复。朋友圈辅助要求手机已解锁、微信在前台。应用双开、工作资料、多账号切换由官方客户端和系统决定；本版不强制多开，也不承诺跨资料通知互通。

## 数据与验证范围

AI 密钥通过 MAUI SecureStorage 保存在手机加密存储中，未从电脑自动迁移；设置、名单和通知指纹只在本机。禁止将真实密钥写进源码或公开配置。安卓备份已关闭。

已通过安卓 Release 构建（0 错误，1 项现有布局过时警告）、签名及安装包清单检查、58 项独立规则与模拟 AI 协议检查。电脑显示的共享页面是 Windows MAUI 布局预览，不是运行 APK；本轮 Windows 自动界面检查等待超时，未通过。布局预览不能代替安卓真机证明。目前没有连接安卓设备，安装、系统权限、真实通知回复、朋友圈点击及 HyperOS 后台表现仍待手机实测。

Windows C# UIA SDK 无法直接在安卓运行。本版手机本地执行层与电脑版分开，电脑版的 SDK、任务、云桥接和已有接口保持可用。
